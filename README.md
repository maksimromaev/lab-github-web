## 📖 О проекте

**Перенос слов** — учебный проект по дисциплине «Программная инженерия».

Дан текст на русском языке. Необходимо отформатировать его строки по заданной длине с помощью **переноса слов**. Как показывают многочисленные эксперименты, разбиение русского слова на части для переноса выполняется *с большой вероятностью правильно*, если пользоваться набором простых приёмов (см. [Правила переноса](#-правила-переноса)). ~~Идеальный перенос по всем правилам орфографии~~ — не цель проекта: алгоритм эвристический и даёт верный результат в подавляющем большинстве случаев.

**Входные данные:** текст на русском языке и максимальная длина строки.
**Результат:** текст, разбитый на строки не длиннее заданной, с переносами слов через дефис.

## 🎯 Цели и задачи

**Цель:** разработать программу автоматического переноса слов для форматирования русского текста по длине строки.

**Задачи:**

- Изучить правила разбиения русских слов на части для переноса
- Реализовать функцию разбиения слова на допустимые части
- Реализовать список приставок, содержащих гласные, для повышения точности
- Реализовать форматирование строк текста по заданной длине
- Протестировать программу на разных текстах и подготовить документацию

## 📐 Правила переноса

Разбиение слова выполняется по следующим приёмам:

1. **Две гласные подряд** можно разделить, если:
   - первой из них предшествует согласная;
   - за второй идёт хотя бы одна буква;
   - буква `й` рассматривается вместе с предшествующей гласной как единое целое.
2. **Две согласные подряд** можно разделить, если:
   - первой из них предшествует гласная;
   - в части слова после второй согласной есть хотя бы одна гласная;
   - буквы `ь` и `ъ` рассматриваются вместе с предшествующей согласной как единое целое.
3. Если пункты 1 и 2 неприменимы, слово разбивается так, чтобы:
   - первая часть содержала **более одной буквы** и оканчивалась на гласную;
   - вторая часть содержала **хотя бы одну гласную**.

> **Улучшение точности:** перед применением правил программа пытается выделить из слова одну из приставок, содержащих гласные (из неполного списка приставок).

### Краткая сводка

| Правило | Что разделяем      | Пример      |
|:-------:|:-------------------|:------------|
| 1       | Две гласные        | `по-эт`     |
| 2       | Две согласные      | `сум-ка`    |
| 3       | По гласной         | `мо-ло-ко`  |

## 💡 Примеры

Строчные примеры переноса: `по-эт`, `сум-ка`, `мо-ло-ко`.

Схема работы алгоритма на псевдокоде:

```text
для каждого слова текста:
    если слово помещается в текущую строку → добавить его
    иначе:
        выделить приставку (если есть)
        найти допустимые места переноса по правилам 1–3
        взять наибольшую часть, которая помещается вместе с дефисом
        остаток слова перенести на следующую строку
```

Пример кода на Python (функция проверки гласной):

```python
VOWELS = set("аеёиоуыэюя")

def is_vowel(ch: str) -> bool:
    return ch.lower() in VOWELS
```
